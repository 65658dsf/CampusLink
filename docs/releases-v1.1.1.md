# 岚连 Campus Link v1.1.1

开发者：**NingMeng123** · [项目主页](https://campuslink.xzncraft.cn/) · [开源仓库](https://github.com/65658dsf/CampusLink)

本版新增锐捷 ePortal Web 校园网支持，并让 Dr.COM 与锐捷方案优先从当前网络发现真实认证地址。原有贵州轻工职业大学 Dr.COM 默认方案保留。

## 本版更新

- **新增锐捷 ePortal Web 适配。** 内置“四川大学 · 锐捷 ePortal”参考方案，支持校园网、移动、电信、联通服务选项；按网页协议执行 RSA 密码变换、登录、在线识别和注销。
- **新增当前网络认证地址发现。** 内置方案默认只读访问 `http://www.msftconnecttest.com/redirect`，从网络返回中识别对应协议的真实认证门户；无法识别时回退已知学校入口。正常 MSN/Bing 跳转不代表校园网认证成功，账号密码不会提交给 Microsoft。
- **新增可导入的锐捷方案。** “连接方案”页面增加“导出锐捷示例”，可配置已知入口、允许的发现中转来源、学校公钥和服务编码；附带 [详细制作教程](https://github.com/65658dsf/CampusLink/blob/v1.1.1/docs/ruijie-guide.md) 与川大参考示例。
- **完善认证结果确认。** 登录和注销后再次查询状态，避免仅凭 HTTP 200 或服务器接受请求就显示完成。未知页面、超时和普通互联网响应不会被当作明确离线。
- **接入现有网络守护。** 成功认证或确认在线后按设定间隔检测，默认 30 秒；明确离线且有可用凭据时重连，手动注销暂停守护。验证码要求交由官方认证页处理，自动认证暂停等待用户操作。
- **完善诊断与隐私处理。** 认证密码、RSA 密文、Cookie、设备参数及会话索引在响应诊断中脱敏。发现缓存只在运行期间复用真实服务器来源，不持久保存临时查询串或 MAC；关闭应用后清除。

| --- | --- |
| `Campus-Link-Setup-1.1.1.exe` | Windows x64 |
| `Campus-Link-1.1.1-mac-x64.dmg` / `.zip` | Intel Mac |
| `Campus-Link-1.1.1-mac-arm64.dmg` / `.zip` | Apple Silicon Mac |

已有用户仍可继续使用原来的 Dr.COM 方案。川大用户在“连接方案”中切换到锐捷方案，并选择账号开通的服务。其他学校请按自己的认证页制作 JSON，不能直接套用川大的服务名称与 RSA 公钥。新增入口发现也不等于自动适配所有学校的协议。

## 验证范围与平台说明

锐捷实现依据公开项目源码、固定加密向量和本机模拟服务验证，**未在四川大学真实校园网验收**。动态门户发现也未完成各校园真实部署的全面验证。支持范围为锐捷 ePortal **网页认证**，不包括 802.1X 客户端、二维码/短信登录和验证码自动识别。

自动化测试使用本机模拟服务，不向真实校园网提交账号或执行注销；打包成功不能替代校内真实连接、断线重连与设备行为验收。

Windows 构建未配置代码签名，系统可能提示未知发布者。macOS 沿用当前发布配置：未提供有效开发者证书与 Apple 公证凭据时，产物为未签名、未公证版本；以随版本提供的 `build-info.json` 记录为准。macOS 可能阻止打开，开机自启动也可能不可用，请核对下载来源并按照系统提示处理，不要关闭系统安全保护。macOS 校园网认证、钥匙串及登录项行为仍需真机验收。

`SHA256SUMS.txt` 提供安装包和 `build-info.json` 的校验值；后者记录源码提交、系统、架构及签名状态。

锐捷协议参考 [LFWQSP2641/scu_net_auto_login](https://github.com/LFWQSP2641/scu_net_auto_login)，保留其 MIT 许可与版权声明。岚连为独立辅助工具，与学校、锐捷、Dr.COM 或 Microsoft 没有官方隶属关系。
