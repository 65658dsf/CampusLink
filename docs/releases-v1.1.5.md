# 岚连 Campus Link v1.1.5

开发者 **NingMeng123** · [项目主页](https://campuslink.xzncraft.cn/) · [开源仓库](https://github.com/65658dsf/CampusLink)

本版提供 28 所高校连接方案和 1 个 Dr.COM 自动识别通用方案，新增深澜 Srun、深信服 Portal，并扩展 Dr.COM 与锐捷 ePortal 的学校参数支持。

## 本版更新

- **扩展高校覆盖。** 新增重庆大学、西南大学，以及湖南科技大学、深圳大学、东南大学、北京理工大学、杭州电子科技大学等 20 所高校。贵州新增贵州师范大学深信服方案、贵州民族大学 Dr.COM 自动识别方案。学校清单、入口和固定版本源码可在接入记录中查阅。[高校接入记录](https://github.com/65658dsf/CampusLink/blob/main/docs/university-adapters.md)
- **自动读取 Dr.COM 参数。** 从当前校园门户的页面、同源脚本和配置读取接口类型、认证端口、账号前缀及服务后缀。连接页支持补充认证地址、端口和前缀，识别结果用于本次认证，登录与注销后独立复核状态。[自动识别说明](https://github.com/65658dsf/CampusLink/blob/main/docs/drcom-auto-guide.md)
- **新增深澜 Srun。** 支持 BX1 挑战应答、对应学校的 HMAC 模式、动态 AC 标识和服务后缀，覆盖北京理工大学、杭州电子科技大学等 8 所高校。
- **扩展锐捷 ePortal。** 西南大学支持从当前门户读取动态 RSA 公钥，新增部分学校使用的明文密码模式及专用表单编码。
- **新增深信服 Portal。** 贵州师范大学支持按当前时间戳生成 RC4 密码和 `auth_tag`，建立同源会话，并复核登录账号与注销后的状态。校区入口变化时可在连接页填写当前认证页。
- **完善方案管理。** 桌面与界面预览共用内置方案目录，新增方案支持搜索、导出及重新导入。修复导入或移除方案保存失败时，内存状态与磁盘配置不一致的问题。

## 安装与升级

在本版本 Releases 按设备选择安装文件。[v1.1.5 下载](https://github.com/65658dsf/CampusLink/releases/tag/v1.1.5)

| 文件 | 适用设备 |
| --- | --- |
| `Campus-Link-Setup-1.1.5.exe` | Windows x64 |
| `Campus-Link-1.1.5-mac-x64.dmg` / `.zip` | Intel Mac |
| `Campus-Link-1.1.5-mac-arm64.dmg` / `.zip` | Apple Silicon Mac |

安装后在“连接方案”搜索学校全名，选择对应服务，再填写校园网账号和密码。Dr.COM 自动识别方案可先保留自动参数，按识别提示补充当前认证页。

## 验证范围

新增高校已完成公开源码对照、本地模拟认证、方案校验和导出导入检查。本地还完成单元测试、类型检查、界面构建及 Windows 桌面回归。新增学校的真实登录、错误密码、在线状态、注销和断线重连仍需校内验收。

贵州师范大学的本校源码来自 2022 年，状态与注销采用同代深信服门户的兼容流程，当前校区部署需校内确认。贵州民族大学公开脚本提供表单和服务选项，缺少完整网关与页面配置，当前接入依赖校园门户自动识别，页面能否完整识别仍需校内验证。贵州 80 所普通高校的逐校检索与证据范围已保存。[贵州复核记录](https://github.com/65658dsf/CampusLink/blob/main/docs/guizhou-sources.json)

发布工作流会在本说明后附加实际签名与公证状态。`build-info.json` 记录源码提交、平台和签名状态，`SHA256SUMS.txt` 提供安装文件与构建记录的校验值。macOS 校园认证、钥匙串、登录项及安装行为仍需真机验收。
