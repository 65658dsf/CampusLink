# 岚连 Campus Link v1.1.4

开发者：**NingMeng123** · [项目主页](https://campuslink.xzncraft.cn/) · [开源仓库](https://github.com/65658dsf/CampusLink)

本补丁按景德镇陶瓷大学实际登录请求修正 v1.1.3 的旧认证入口，并补齐网页确认的运营商账号后缀。

## 本版更新

- **修正景陶登录端口和路径。** 认证页继续使用 HTTP 80 端口，登录改为同主机 801 端口的 `/eportal/portal/login`，匹配 `jsVersion=4.2.1`、`terminal_type=1` 和重复 `lang` 字段。AC IP 和名称按实际请求留空，设备 IP 动态读取。
- **补齐网页运营商选项。** 中国电信、中国移动、中国联通及学校原名“测试”，分别补上 `@telecom`、`@cmcc`、`@unicom`、`@xyw`，已有正确后缀时不重复追加；“其他”保留完整账号。“测试”不另称校园网，密码仅做 URL 编码。
- **保留实际业务拒绝提示。** 已核对 `result=0`、`ret_code=1` 的密码错误响应；遇到“云陶密码错误，请登录云上陶大修改密码”时，按提示在“云上陶大”修改密码后重试，不把 HTTP 200 当认证成功。
- **加强在线状态确认。** 新版状态查询需要明确在线结果、账号身份与有效 IP，身份信息不足时使用新读取页面的唯一状态标记复核。未知状态不会触发自动重连；兼容注销改为 801 端口 `/eportal/portal/logout` 并独立确认离线。
- **保留旧导入方案。** 新版通过 `drcomEportal: { "variant": "portal-v4", "apiPort": 801 }` 显式启用；旧 JSON 省略该配置时保持旧流程，不自动改写用户定义。内置景陶方案和仓库示例已更新，配置版本为 `1.1.0`。

## 验证范围

本次已取得实际登录请求、网页运营商选项及密码错误的失败响应，**仍没有成功响应，也未完成真实校园网成功登录验收**。端口、字段、后缀及失败处理已有依据；各类账号的真实登录、在线状态和注销仍需校内验证。兼容注销依据同家族公开实现，不作为景陶实测结论。

自动化检查使用脱敏样例和本机模拟服务，覆盖请求编码、端口和运营商处理、状态复核、方案校验、发布流程、类型检查、界面构建及 Windows 桌面流程，不重放真实账号请求。

Windows 当前未配置代码签名。macOS 签名与公证状态以本次构建记录为准；未签名或未公证时系统可能阻止打开，开机自启动也可能不可用。macOS 校园认证、钥匙串、登录项和安装行为仍需真机验收。

`build-info.json` 记录源码提交、平台与签名状态；`SHA256SUMS.txt` 提供安装文件和构建记录的校验值。
