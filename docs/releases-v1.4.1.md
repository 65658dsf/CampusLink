# 岚连 · CDUTYB 专版（液态玻璃版）v1.4.1

本次更新聚焦界面默认形态、首次使用体验与更新通道。

## 本版更新

- **默认界面改为液态玻璃**：新安装默认启用液态玻璃界面，仍可在「应用设置 → 界面外观」一键切回经典；已保存外观偏好的用户不受影响。
- **首次启动引导优化**：即使当前校园网已登录，也可以直接输入并保存正在使用的账号密码；保存后不影响当前会话，自动连接与断线守护可正常使用。
- **软件更新提示**：正式安装版启动时会检查 GitHub Releases，发现新版本可一键前往发布页下载；也可选择「暂不更新」，该版本不再重复提醒。应用设置中新增「检查更新」入口。
- **开发日志新增本项目仓库入口**：可直接打开 GitHub 项目主页，查看源码、Issue 与全部发布。
- 界面细节：修复顶栏残留框线并收窄高度；侧边栏四角恢复圆角；导航选中高亮改为滑块式滑动；切换界面外观带过场动画。

## 下载与安装

- Windows：下载 `Campus-Link-Glass-Setup-1.4.1.exe` 安装；未签名安装包可能触发 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。
- macOS：按芯片选择 x64 / arm64 的 DMG 或 ZIP；未签名构建可能被 Gatekeeper 拦截。
- 安装包可与「岚连 · CDUTYB 专版（经典版）」共存，设置与数据相互独立。
