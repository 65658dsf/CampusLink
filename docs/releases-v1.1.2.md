# 岚连 Campus Link v1.1.2

开发者：**NingMeng123** · [项目主页](https://campuslink.xzncraft.cn/) · [开源仓库](https://github.com/65658dsf/CampusLink)

本版改善首次使用和方案查找体验，并整合 PR #1 的学校适配、网络守护及诊断功能。

## 本版更新

- **首次启动不预选方案。** 引导用户前往“连接方案”选择学校；选择前不探测学校认证服务器，也不自动认证。已有用户保留保存的方案；移除当前外部方案后回到待选择状态。
- **新增方案搜索。** 支持按学校、名称、描述、作者或协议查找内置及导入方案，提供清空搜索和无匹配结果提示。三种内置学校方案均直接展示。
- **新增成都理工大学（宜宾校区）锐捷 ePortal 方案。** 支持空网络服务、账号与查询串双重编码，密码沿用 `密码>mac` RSA 流程；修复成功页自刷新和同路径设备参数跳转的识别。
- **增强网络守护和托盘。** 本机 IPv4 地址变化时触发静默检测；托盘展示 IP 与在线时长，可暂停或恢复守护。新用户检测间隔为 10 秒，旧用户保持原有设置。
- **新增安全账号密码管理。** 选择方案后可在设置中保存凭据，继续使用 Electron `safeStorage` 加密；不保存明文密码，系统加密不可用时拒绝保存。
- **新增脱敏诊断导出。** 导出应用信息、网络概况、当前方案与运行日志；账号打码，自定义参数值隐藏，移除密码、Cookie、MAC 及 URL 查询信息。
- **完善日常使用体验。** 新增开发日志、概览账号信息、吸顶标题栏与常见锐捷拒绝原因提示；保留软件更新检查和方案 JSON 导出。

## 安装与升级

在 [本版本 Releases](https://github.com/65658dsf/CampusLink/releases/tag/v1.1.2) 按系统与处理器选择：

| 文件 | 适用设备 |
| --- | --- |
| `Campus-Link-Setup-1.1.2.exe` | Windows x64 |
| `Campus-Link-1.1.2-mac-x64.dmg` / `.zip` | Intel Mac |
| `Campus-Link-1.1.2-mac-arm64.dmg` / `.zip` | Apple Silicon Mac |

已有用户沿用账号、已选方案、加密密码与检测间隔。新用户需先选择方案，再填写校园网账号密码。其他学校应导入与实际认证页匹配的 JSON，内置学校方案不能直接代表所有锐捷或 Dr.COM 部署。

## 验证范围

自动化检查涵盖单元测试、发布脚本、TypeScript、界面构建及 Windows 本机模拟服务桌面流程。认证测试使用本地模拟服务器，不向真实校园网提交账号或执行注销。成都理工大学宜宾校区参数依据 PR 提供的抓包与实现整合，本次未在该校真实网络验收。

Windows 当前未配置代码签名。macOS 签名与公证状态以构建记录为准；未签名或未公证时系统可能阻止打开，开机自启动也可能不可用。macOS 校园认证、钥匙串、登录项及安装行为仍需真机验收。

`build-info.json` 记录源码提交、平台与签名状态；`SHA256SUMS.txt` 提供安装文件和构建记录的校验值。
